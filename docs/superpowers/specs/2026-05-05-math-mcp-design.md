# math-mcp Design

## Purpose

A minimal Model Context Protocol (MCP) server exposing the four basic arithmetic operations as tools: `add`, `subtract`, `multiply`, and `divide`. Serves over Streamable HTTP on both plain HTTP and HTTPS so it can be reached from remote workstations.

## Stack

- **Language:** Python 3.10+
- **Framework:** [`mcp`](https://pypi.org/project/mcp/) Python SDK, using `FastMCP` (high-level decorator API)
- **Transport:** Streamable HTTP (FastMCP's `streamable_http_app()` mounted in `uvicorn`)
- **TLS:** Self-signed cert generated locally; CN/SAN fixed to `localhost`
- **Other deps:** `uvicorn`, `cryptography`
- **Dependency manager:** `uv` recommended; `pip` also works

## Architecture

A single `FastMCP` instance defines the four tools and exposes its ASGI app via `streamable_http_app()`. The same app is mounted in **two `uvicorn` servers running concurrently in one process** via `asyncio.gather`:

- HTTP listener on `0.0.0.0:<http_port>` (default `52080`)
- HTTPS listener on `0.0.0.0:<https_port>` (default `52443`), using the generated cert/key

The MCP endpoint path is `/mcp` (FastMCP's default). Clients connect to:
- `http://<host>:52080/mcp`
- `https://<host>:52443/mcp`

## Setup script (`setup.py`)

Interactive script run once before first server start. Refuses to silently overwrite existing state.

**Prompts (each shows a default the user can accept by pressing Enter):**

| Prompt                       | Default | Notes                                        |
|------------------------------|---------|----------------------------------------------|
| HTTP port                    | `52080` | Validated as int in `1..65535`               |
| HTTPS port                   | `52443` | Validated as int in `1..65535`; must differ from HTTP port |
| Cert validity (days)         | `365`   | Validated as positive int                    |
| Log level                    | `info`  | One of `debug`, `info`, `warning`, `error`   |
| Overwrite existing certs?    | `no`    | **Only asked if `certs/cert.pem` already exists.** If `no`, keeps existing certs. |

**Cert generation:** RSA 2048-bit key, self-signed X.509 cert with:
- Subject CN = `localhost`
- Subject Alternative Name (SAN) DNSName = `localhost`
- Validity = chosen days from now
- Written to `certs/cert.pem` and `certs/key.pem` with mode `0600` on the key

**Output:** writes `config.json` with the chosen ports and log level. Prints a final "Setup complete — run `uv run server.py` to start" message.

## Server script (`server.py`)

- Reads `config.json`. If missing, prints "Config not found. Run `uv run setup.py` first." and exits non-zero.
- Reads `certs/cert.pem` and `certs/key.pem`. If missing, prints similar message and exits.
- Builds the FastMCP app, gets `app = mcp.streamable_http_app()`.
- Configures two `uvicorn.Config` objects (one HTTP, one HTTPS with `ssl_certfile`/`ssl_keyfile`), bound to `0.0.0.0`.
- Runs both `uvicorn.Server(...).serve()` concurrently with `asyncio.gather`.
- Logs startup banner showing both URLs.

## Tools

Each tool accepts two `float` arguments and returns a `float`. The MCP SDK derives the input schema from Python type hints; the docstring becomes the tool description.

| Tool       | Signature                                | Behavior                                    |
|------------|------------------------------------------|---------------------------------------------|
| `add`      | `add(a: float, b: float) -> float`       | Returns `a + b`                             |
| `subtract` | `subtract(a: float, b: float) -> float`  | Returns `a - b`                             |
| `multiply` | `multiply(a: float, b: float) -> float`  | Returns `a * b`                             |
| `divide`   | `divide(a: float, b: float) -> float`    | Returns `a / b`; raises `ValueError("Division by zero")` when `b == 0` |

## Error handling

- **`divide` by zero:** raises `ValueError`; FastMCP converts this to an MCP tool error response surfaced to the client.
- **Missing config / certs:** server exits with a clear message pointing at `setup.py`.
- **Port conflict:** uvicorn's bind error propagates and the process exits — message is sufficient for diagnosis.

## TLS notes

The cert's SAN is fixed to `localhost`, so remote clients connecting by IP or hostname will see a TLS hostname-mismatch warning. This is intentional for simplicity. Remote clients are expected to either (a) skip TLS verification in their MCP client config, or (b) use the plain-HTTP listener on `52080`. Documenting this is part of the README.

## Running

```sh
uv run setup.py     # one-time: prompts, generates certs, writes config.json
uv run server.py    # starts both HTTP (52080) and HTTPS (52443) listeners
```

Example client config (Claude Desktop / Claude Code):
```json
{
  "mcpServers": {
    "math": {
      "url": "http://<server-host>:52080/mcp"
    }
  }
}
```

## Out of scope

- Additional operators (modulo, power, roots, etc.)
- Vector or matrix math
- Arbitrary-precision arithmetic
- stdio transport
- Authentication / authorization
- Persistent state or history
- Cert rotation / renewal beyond manual re-run of `setup.py`
- CA-issued / Let's Encrypt certs
